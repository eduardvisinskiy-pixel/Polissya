# Полісся-Продукт — сайт

Статичний сайт без збірки: чистий HTML + CSS + JS. Нічого встановлювати не потрібно.

## Файли

```
index.html    розмітка (шапка, футер, SEO-метадані, JSON-LD)
styles.css    усі стилі
data.js       контент: акції, новини, вакансії, магазини, телефони, код адмінки
app.js        логіка: сторінки, галерея листівок, фільтри, адмін-панель
map.html      карта магазинів (окремий iframe)
assets/       логотип, фавікон, фото
```

## Запуск локально

Просто відкрийте `index.html` у браузері. Або, щоб карта й фото коректно завантажувались:

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Публікація на GitHub Pages

1. Створіть репозиторій і завантажте вміст цієї папки в корінь.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через хвилину сайт буде на `https://<логін>.github.io/<репозиторій>/`.

## Адмін-панель

Вхід приховано від покупців — у меню її немає. Два способи відкрити:

- клавіші **Ctrl + Shift + A**
- **5 кліків** по рядку «© 2026 ТОВ ТК «Полісся-Продукт»» у футері

Вхід **не запам'ятовується**: після перезавантаження сторінки кнопка «Адмінка» знову зникає й код потрібно ввести ще раз.

Далі — службовий код. Змінюється в `data.js`:

```js
const ADMIN_PIN = '2002';
```

> Це захист від випадкового заходу покупця, а не серверна авторизація. Для справжнього захисту потрібен бекенд.

Що редагується: **Акції** (каталоги + фото сторінок), **Новини**, **Вакансії**, **Піца** (список піцерій і меню).

## Де зберігаються дані

Усе, що ви змінюєте в адмінці, лежить у `localStorage` браузера — тобто лише на тому комп'ютері, де редагували. Стартові значення беруться з `data.js`.

Щоб зміни бачили **всі відвідувачі**, є два шляхи:

1. **Без бекенду:** внести правки в `data.js` і закомітити (адмінка тоді — інструмент попереднього перегляду).
2. **З бекендом:** підключити API або headless CMS замість `localStorage` — у `app.js` за це відповідають функції `load()` / `save()`, замінити потрібно тільки їх.

Ключі в localStorage: `polissya.promos.v5`, `polissya.news.v1`, `polissya.jobs.v1`, `polissya.pizzerias.v2`, `polissya.pizzas.v1`.

## Розміри фото

| Що | Пропорції | Рекомендовано |
|---|---|---|
| Обкладинка акції | 4:3 | 1600×1200 px |
| Сторінки листівки | як є | ширина 1600–1900 px |
| Фото новини | 16:10 | 1600×1000 px |
| Фото піци | 4:3 | 1200×900 px |

Підказки з розмірами дублюються в самій адмін-панелі під кожним полем завантаження.

## Що варто зробити далі

- Частина фото підтягується напряму з `polissya-product.ua` — краще перекласти їх у `assets/`, щоб не залежати від старого сайту.
- Ціни піц і номери піцерій на старому сайті існують лише всередині картинок. Поки списки в адмінці порожні, на сторінці показується та сама листівка; заповніть списки — з'являться нормальні картки.
